# Sistema de Gestão para Clínica Médica

## Objetivo

O Sistema de Gestão para Clínica Médica tem como objetivo centralizar e otimizar os processos administrativos e clínicos de uma clínica médica por meio de uma aplicação web moderna, segura e escalável.

A plataforma permitirá que recepcionistas, médicos e administradores realizem suas atividades em um único ambiente, garantindo maior organização, rastreabilidade e segurança das informações.

---

# Objetivos do Projeto

- Centralizar informações da clínica.
- Facilitar o gerenciamento de pacientes.
- Organizar agendas médicas.
- Controlar consultas e atendimentos.
- Registrar prontuários eletrônicos.
- Emitir receitas e atestados.
- Disponibilizar dashboards gerenciais.
- Garantir rastreabilidade através de auditoria.

---

# Perfis do Sistema

## Administrador

Responsável pela administração completa do sistema.

Funcionalidades:

- Gerenciar usuários
- Gerenciar médicos
- Gerenciar especialidades
- Consultar auditorias
- Configurar parâmetros

---

## Recepcionista

Responsável pelo atendimento administrativo.

Funcionalidades:

- Cadastrar pacientes
- Atualizar cadastro
- Agendar consultas
- Confirmar consultas
- Cancelar consultas
- Consultar agendas

---

## Médico

Responsável pelos atendimentos.

Funcionalidades:

- Visualizar agenda
- Iniciar consultas
- Registrar prontuários
- Emitir receitas
- Emitir atestados
- Finalizar consultas
